title: Citation Desk
oneLiner: An answer desk that refuses to speak without a source.
stack:
  - Python
  - FastAPI
  - SQLite
updatedAt: "2026-10-14"
claim: >-
  Every answer Citation Desk returns cites one or more retrieved passages:
  across the 12-question fixture on 2026-10-14, 12 answers carried a citation
  and 0 uncited answers shipped.
problem: >-
  The generator could answer from model memory when retrieval returned nothing.
  Those answers read as fluent, but a reader could not trace a sentence to a
  document.
constraint: >-
  The service had to run on SQLite FTS5 with no external model at request time,
  and every answer had to carry passage ids that the validator could resolve
  against the current corpus.
architecture: >-
  Upload writes chunks and a document version to SQLite. A question runs an
  FTS5 query, takes the top 5 passages, asks the answer model for a structured
  response, and the validator rejects the response when any passage id is
  absent from the current version. A rejected response becomes a refusal.
decisions:
  - title: Refuse rather than answer without a source
    choice: >-
      Return a refusal when retrieval finds no passage above the score floor.
    rejected: >-
      A confidence threshold on generated text. A confident sentence with no
      passage still looked correct to a reviewer, and the fixture could not map
      it to a source.
    cost: >-
      The desk refuses 3 of 12 seeded questions when retrieval returns no
      passage above the floor, so coverage is lower than a free-form answer.
    evidence: >-
      The refusal count is 3 in the 12-question fixture, and each refusal names
      the query that returned no passage.
  - title: FTS5 instead of embeddings
    choice: >-
      Use SQLite FTS5 retrieval and keep the corpus in one file.
    rejected: >-
      Local embeddings with a vector index. It gained 1 correct answer on the
      12-question fixture, but added a 400 MB model and a 3 s cold start.
    cost: >-
      Paraphrase matches are missed; 2 of 12 fixture questions needed a keyword
      rewrite before retrieval found the passage.
    evidence: >-
      The 12-question fixture records 12 cited answers and 3 refusals without a
      model download.
  - title: Passage ids in the answer schema
    choice: >-
      Require a JSON response with a passage id for each claim and validate
      every id before rendering.
    rejected: >-
      Ask the model to cite in prose. A regex mapped 10 of 12 citations to a
      passage, and 2 answers passed with a broken reference.
    cost: >-
      Every answer path needs a post-generation validator, and a failed
      validation returns a refusal instead of text.
    evidence: >-
      The validator rejects a response with an unknown passage id in the fixture
      and the request returns a refusal.

    processChange: >-
