title: E-commerce platform
oneLiner: A hosted storefront whose sandbox checkout moves an order to PAID through a signed Stripe webhook, with stock decided under concurrency.
stack:
  - Next.js
  - TypeScript
  - PostgreSQL
  - Prisma
claim: >-
  A recorded run of 20 concurrent checkouts against stock 5 created 5 orders
  and 15 rejections, leaving stock 0 and 5 open reservations.
what: >-
  A seeded Next.js 15 storefront on PostgreSQL 16 with accounts, cart and
  admin. Checkout turns a cart into an order, reserves stock and creates a
  Stripe PaymentIntent from the total. A signed webhook moves the order to
  PAID, and a recorded replay answers 200 duplicate.
hardPart: >-
  Stock, price and idempotency are decided under concurrency. Reading stock
  then writing a reservation lets concurrent buyers observe the same last
  unit; a retried submit can create a second order; a client can post a total
  the server did not compute. The database arbitrates each.
decision:
  title: The conditional UPDATE is the stock arbiter
  choice: >-
    Decrement with UPDATE ... WHERE stock >= $qty inside the checkout
    transaction; a zero-row update aborts it as OUT_OF_STOCK.
  rejected: >-
    Read, check in application code, then write in a second statement;
    concurrent buyers can pass the read for the last unit.
  cost: >-
    The loser pays for a rollback, and checkouts serialise on the variant row.
  evidence: >-
    The recorded run returned 5 orders and 15 rejections on stock 5.
failures:
  - summary: >-
      Two buyers reach the last unit at the same moment, or a client posts its
      own total and retries the submit. The system resolves every such request
      to one order or an explicit refusal.
    mechanism: >-
      Price is recomputed from the cart inside the checkout transaction; the
      conditional UPDATE decrements stock while stock >= qty and returns zero
      rows otherwise; the (userId, idempotencyKey) unique constraint folds a
      retry into the existing order. A zero-row update aborts the transaction
      as OUT_OF_STOCK.
measured: >-
  Recorded hosted payment: order KST-2610-53808809, a 14900-cent PaymentIntent,
  one signed webhook delivery, and a replay answering 200 duplicate. Four
  invariants hold: a forged total is ignored; one order per (userId,
  idempotencyKey); 20 concurrent checkouts on stock 5 produced 5 orders and 15
  rejections; a replayed webhook is a 200 no-op. The gate recorded 181 tests
  across 33 files and 5 Playwright tests. The load run measured p95 4.58 s over
  250 requests, with 2 P2028 timeouts.
