updatedAt: "2026-10-23"
claim: >-
  The local release lane rolled back a build after its smoke gate failed, and
  deploy.log records the order; the GitHub Actions lane has never run.
what: >-
  A Fastify invoice API on PostgreSQL 16 with a GitHub Actions workflow, a
  Dockerfile and a local release script. The workflow defines eight gates and
  a ci-ok aggregator; the release script swaps a current pointer, waits on
  /health and /ready, runs five smoke assertions and can roll back.
hardPart: >-
  A workflow file can declare gates that have never run, and a health check can
  pass while the service is broken. The repository has no remote, so the
  Actions lane cannot execute here; a release lane without a rollback step can
  leave a bad process serving.
decision:
  title: Smoke failure rolls back; health is not a deploy gate
  choice: >-
    After the health wait, run five smoke assertions and roll back when any
    fails, then re-smoke the restored release.
  rejected: >-
    Treat healthy /health and /ready responses as success; a build can stay
    healthy while its invoice route fails.
  cost: >-
    Every release pays for five live assertions and a rollback restart, and
    rollback returns to the previous release.
  evidence: >-
    deploy.log records deploy.start, health.ok, smoke.fail, rollback.start,
    rollback.health.ok, rollback.smoke.ok.
failures:
